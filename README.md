# TDM 상용차 데일리 클리핑

국내 중대형 상용차 시장의 유튜브 여론·경쟁사 채널 동향·커뮤니티 이슈를 모니터링하는 자동 클리핑입니다.

**웹으로 보기 →** https://jooosanghyun.github.io/tdm-clipping/

## 구성
- `index.html` — 아카이브 (자동 생성, `build_index.py` 실행)
- `clippings/YYYY-MM-DD.html` — 일자별 클리핑

## 수집 소스
- YouTube Data API v3 — 경쟁사 공식 채널 6곳 + 상용차 인플루언서 3곳 (신규 영상·조회수·댓글 VOC)
- 상용차신문 — 시장·정책·행사
- 보배드림 트럭·버스·중기 게시판 — 커뮤니티 여론

## 발행 규칙
- 평일 자동 실행, **신규 콘텐츠가 있는 날만** 발행
- 공개 저장소이므로 내부 실적·사업계획 수치는 포함하지 않음
- 인용된 댓글·게시글은 개인 의견이며, 시사점은 분석 의견입니다
